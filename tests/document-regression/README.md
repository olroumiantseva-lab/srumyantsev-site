# Regression pack: «Разобрать документ»

12 синтетических кейсов для ручного/regression теста загрузки, бесплатного preview и полного разбора за 290 ₽. Все данные вымышлены.

## Как прогонять

Для каждого кейса:
1. Загрузить указанные файлы на `/tools/document/`.
2. Прогнать 4 preview-режима: `plain`, `wants`, `actions`, `attention`.
3. Проверить `preview_must` и `must_not_hallucinate` из `matrix.json`.
4. Один раз выполнить полный платный разбор (на тестовой среде/кредите) и проверить `paid_must`.
5. Оценить 6 бинарных критериев: ingestion, document type, no hallucinations, key facts, preview value, paid uplift.

Итого: 48 preview-прогонов + 12 полных = 60. Максимум по основной матрице — 72 балла. Целевой порог — 65/72 при нуле критических галлюцинаций.

## Важное

- Не считать отсутствие юридической/медицинской категоричности ошибкой: сервис не должен изображать профильного специалиста.
- Любая выдуманная сумма, срок, обязанность, диагноз или гарантия — критический дефект.
- Для изображений и сканов сначала отдельно фиксировать качество OCR; нельзя списывать ошибку распознавания на аналитический промпт.
- Кейc 06 хранится в PNG в эталонном пакете; HEIC-путь проверяется отдельно на реальном iPhone-фото, потому что генератор CI не содержит HEVC encoder.
