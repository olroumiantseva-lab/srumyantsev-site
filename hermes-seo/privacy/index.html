Политика конфиденциальности Hermes SEO Readonly

Эта политика описывает работу внутреннего инструмента Hermes SEO Readonly, используемого Сергеем Румянцевым для анализа эффективности собственных сайтов в Google Search Console. Контакт по вопросам данных: olroumiantseva@gmail.com.

1. Какие данные получает инструмент

После разрешения владельца Google-аккаунта инструмент использует область доступа https://www.googleapis.com/auth/webmasters.readonly и получает только доступные ему данные Google Search Console: перечень разрешённых ресурсов, поисковые запросы, URL страниц, показы, клики, CTR, среднюю позицию и периоды статистики.

Для технического доступа используются OAuth-учётные данные и токены. Инструмент не запрашивает доступ к письмам Gmail, контактам, файлам Google Drive или паролям Google.

2. Цели использования

Данные нужны для оценки SEO-эффективности сайтов, обнаружения поисковых возможностей, подготовки рекомендаций по контенту и отслеживания изменений показателей. Данные Google не используются для рекламы, продажи профилей пользователей или целей, не связанных с заявленной аналитикой.

3. Хранение и защита

OAuth-токены и отчёты хранятся в закрытой рабочей среде на сервере владельца инструмента. Доступ к файлам ограничивается учётными записями и правами операционной системы. Отчёты сохраняются для сравнения показателей во времени; по прекращении работы с инструментом владелец может удалить сохранённые данные и учётные данные.

4. Передача данных сторонним поставщикам

Для анализа SEO-отчётов часть сведений из Google Search Console может передаваться выбранному поставщику ИИ-модели, в том числе через подключение OpenAI Codex, исключительно для подготовки рекомендаций. Передаются необходимые для задачи данные, а не OAuth-пароли или refresh-токены. Доступ к данным также может обеспечиваться инфраструктурным поставщикам в объёме, необходимом для работы и хранения сервиса.

Данные не продаются и не передаются рекламным посредникам. Использование данных Google ограничивается описанными здесь целями.

5. Доступ и отзыв разрешения

Владелец Google-аккаунта может отозвать разрешение Hermes SEO Readonly в настройках подключений Google-аккаунта. После отзыва новые обращения к Google Search Console от имени аккаунта прекращаются, когда действующие права перестанут работать. Для запроса удаления локальных копий данных можно написать на olroumiantseva@gmail.com.

6. Изменения политики

При изменении состава получаемых данных, целей или сторонних поставщиков эта страница обновляется. Актуальная версия всегда доступна по адресу srumyantsev.ru/hermes-seo/privacy/.
