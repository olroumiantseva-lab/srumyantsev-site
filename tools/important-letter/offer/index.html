Публичная оферта

1. Предмет

Исполнитель предоставляет разовую информационную услугу по автоматизированной подготовке текста письма на основании сведений пользователя.

2. Результат

После оплаты пользователь получает полный текст письма, тему, при необходимости список приложений и рекомендации по проверке и отправке.

3. Цена и порядок

Стоимость одного полного письма — 390 рублей. До оплаты пользователь получает бесплатный фрагмент. Оплата проводится через Robokassa. Услуга считается оказанной после открытия полного результата.

4. Ограничения

Сервис работает только с данными пользователя, не устанавливает факты, не гарантирует юридический или иной результат и не заменяет профессиональную консультацию. Пользователь самостоятельно проверяет важные даты, суммы, реквизиты и утверждения перед отправкой.

5. Возврат и данные

Порядок возврата указан на странице «Возвраты». Обработка данных описана в политике конфиденциальности.
