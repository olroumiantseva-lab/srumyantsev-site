# Двухуровневая навигация `/guides/`

## Цель

Перестроить каталог 33 существующих гайдов по ступеням и задачам без изменения URL, canonical, sitemap и robots.txt.

## Решение

1. Хранить классификацию и карточечные данные в `guides/guides-registry.json`.
2. Генерировать статический `guides/index.html` из реестра: все 30 ссылок остаются в HTML без JavaScript.
3. Использовать небольшой JS только для фильтрации уже отрендеренных карточек.
4. Из того же реестра обновлять мета-зону и нижнюю навигацию страниц гайдов.
5. Проверять реестр, HTML, canonical, ссылки и JS автоматическим preflight-тестом.

## Фазы

- Реестр и снимок canonical.
- Каталог, стили и фильтрация.
- Мета-зоны и навигация материалов.
- Контракт публикационного SKILL.
- Автоматическая и визуальная проверка.

## Границы

- Только 33 существующих гайда.
- Практикумы не затрагиваются.
- Новые страницы и URL не создаются.
- `sitemap.xml` и `robots.txt` не меняются.
- Commit и push выполняются только после отдельного разрешения.

## Критерии приёмки

- 33 карточки и 33 уникальных существующих URL.
- Маршруты: 6 / 7 / 6; практические: 6 / 8 / 0.
- `kak-ne-poteryat-perepiski-s-ii`: level 1, route, position 7.
- Все карточки доступны без JavaScript.
- Фильтр не выдаёт ошибок и не создаёт URL.
- Canonical всех страниц совпадают со снимком до изменений.
- Внутренние ссылки разрешаются локально.
- Desktop и mobile проходят визуальную проверку.
